# 🧠 AI-Powered Real Estate Price Predictor – End-to-End ML Project

This project demonstrates how **AI and Machine Learning** can enhance **real estate investment decisions** by accurately predicting housing prices using advanced models and explainable AI.

> 📌 Built entirely in Google Colab with rich visualizations, model tuning, SHAP explainability, and real-world simulation.

---

## 🔍 Project Overview

- **Objective**: Predict house sale prices using the Ames Housing Dataset.
- **Goal**: Help buyers, sellers, and real estate analysts make smarter pricing decisions using AI.

---

## 🚀 Key Features

✅ **Real-World Dataset** – 80+ house attributes from Ames, Iowa  
✅ **Advanced Feature Engineering** – Added 5+ intelligent features like `House_Age`, `Has_Basement`, `Total_SF`  
✅ **ML Models Compared** – Linear Regression, Random Forest, Tuned RF, XGBoost, LightGBM  
✅ **Explainable AI** – SHAP plots to interpret feature importance  
✅ **Investment Simulation** – Dynamic animation to show price impact when increasing square footage  
✅ **Final Model** – Tuned Random Forest with R² = `0.8871`
